# codemirror-lang-egglog

[egglog](https://github.com/egraphs-good/egglog) language support for
[CodeMirror 6](https://codemirror.net/): a Lezer parser with highlighting, list folding,
Lisp-style indentation and keyword completion.

```js
import {EditorView, basicSetup} from "codemirror"
import {egglog} from "codemirror-lang-egglog"

new EditorView({extensions: [basicSetup, egglog()], parent: document.body})
```

`egglog()` returns a `LanguageSupport`; `egglogLanguage` is the `LRLanguage`.

## egglog version

The keyword tables are read from egglog's parser, `src/ast/parse.rs`, at the release
recorded in `package.json` under `egglog.version`: currently egglog 3.0.0.

## What the tests show

- Every `.egg` file under egglog's `tests/` at that release that `egglog --mode desugar`
  accepts (157 of 186) parses without error nodes.
- Commands, actions and schedules are told apart by head position: commands at top level,
  schedules nested, actions in both; `run` is a command at top level and a schedule nested.
  A keyword outside head position is an `Atom`. Commands nested in a list other than `fail`
  are still marked `CommandKeyword`, although egglog reads them as function calls there.
- Atoms are classified as egglog classifies them: `true`/`false`, then `i64`, then `NaN`,
  `inf`, `-inf` and finite `f64` (an integer outside `i64` is a `Float`, `1e999` an `Atom`).
- Nothing about types, arity or option placement is checked: `(rule 1)` parses.

## Generated and hand-written

Generated by `pnpm generate` in the [lang-egglog](https://github.com/jcschuster/lang-egglog)
repository, from `spec/keywords.json` (itself extracted from `parse.rs`):

- the keyword rules of `src/egglog.grammar`, between its `generated` markers;
- `src/keywords.ts`, the lists that completion offers.

Hand-written:

- `src/egglog.grammar` outside the generated block;
- `src/tokens.ts`, the tokenizer for atoms, numbers, booleans, `_` and options;
- `src/highlight.ts`, `src/index.ts`, and the `.d.ts` files in `src/`.

## Nodes

`List`, `Unit` (`()`), `CommandKeyword`, `ActionKeyword`, `ScheduleKeyword`, `Callee`
(any other head), `Atom`, `Option` (`:`-atoms), `Wildcard` (`_`), `Bool`, `Integer`,
`Float`, `String`, `LineComment`, and the tokens `"("` and `")"`.
